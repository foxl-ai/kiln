# Feature parity: vLLM and SGLang on Neuron

The product goal: every core serving feature of the LATEST vLLM and SGLang, running on
Trainium and Inferentia. This table is the backlog and the scoreboard.

Sources, read 2026-10-02:
- vLLM **v0.30.0** (2026-09-22): release notes v0.25.0..v0.30.0, `docs/features/*`,
  `docs/design/*` at `main`.
- SGLang **v0.5.21** (2026-10-02): release notes v0.5.16..v0.5.21,
  `docs/docs/advanced_features/*` at `main`.
- For scale: vllm-neuron 0.24.0.1.1.0, the newest managed path, pins vLLM **0.24** (six
  releases behind) and runs on trn2/trn3 only.

Status: **done** (implemented and tested), **next** (in progress or queued), **planned**,
**n/a** (CUDA-specific mechanism with no Neuron analogue; the goal it serves is covered by
another row). "Neuron design" is how the feature maps onto static-shape AOT graphs.
