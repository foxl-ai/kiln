## One linear-attention layer (random bf16 weights) against the same layer in fp32 on the host

```
python tools/profile_linear_attn.py --batch 8 --chunk 128 [--parts]          # GDN, Qwen3.5-0.8B shapes
python tools/profile_linear_attn.py --batch 1 --chunk 32
python tools/profile_linear_attn.py --kind kda --heads 32 --dim 128 --hidden 2304 --batch 8 --chunk 128   # Kimi-Linear-48B shapes
```

Two prefill chunks (the second continues the first's state through the pool, padded) and four
decode steps; time per call chained, at most 6 in flight.
